# Menjiro Ramen website

One-page site for Menjiro Ramen, #109, 2920 Calgary Trail NW, Edmonton. Live at https://menjiroramen.ca (GitHub Pages).

- `index.html` holds everything: page, styles, menu data and hours.
- Menu items and prices are in the `MENU` list near the bottom of `index.html`.
- Opening hours appear twice: the table in the "Hours" section and `HOURS` in the script (plus the `application/ld+json` block for Google). Change all three together.
- Photos live in `images/`, resized for the web with location data removed.
